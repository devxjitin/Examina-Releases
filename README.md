# Examina

**Your AI-powered practice partner for MCQ, theory, and coding questions.**

This repo hosts downloadable builds only — the source code lives in a
private repository.

> **Intended use:** authorized practice and self-study only (e.g. testing
> yourself against practice questions you're allowed to use AI on). Do not
> use this on live, proctored, or graded assessments, or in any context
> where using an automated tool is not explicitly permitted -- that's an
> academic-integrity violation at most institutions and may violate the
> assessment platform's terms of use.

## Download

Grab the latest build from **[Releases](https://github.com/devxjitin/Examina-Releases/releases/latest)** --
`Examina.exe` (the app).
